📱 Cara Bikin APK dari PWA ini

Opsi 1: PWA Builder (Paling Gampang)
1. Deploy app ini ke GitHub Pages / Netlify / Vercel
2. Buka pwabuilder.com
3. Masukkan URL app tuan
4. Klik "Package for Stores" → pilih Android
5. Download APK, install di HP
Opsi 2: Capacitor (Advanced)
1. Butuh Termux/PC
2. npm install -g @capacitor/cli
3. npx cap init
4. Copy folder web ke www/
5. npx cap add android
6. npx cap open android → build
Opsi 3: WebIntoApp
1. Buka webintoapp.com
2. Input URL app tuan
3. Pilih template → generate APK
4. Download + install
💡 Rekomendasi: PWA Builder (Opsi 1). Gratis, gak perlu coding, hasil APK signed & installable.
